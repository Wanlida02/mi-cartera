# mi-cartera

App integrada de inversión value: Inicio (dashboard), Cartera, Cribado, Valoración y Resultados.

- El código y los precios de mercado viven en este repositorio (público).
- Los datos personales (posiciones, fichas, watchlist) viven en el Google Drive del usuario, nunca aquí.
- Los precios se actualizan con una tarea programada de GitHub Actions, sin depender de Claude.
